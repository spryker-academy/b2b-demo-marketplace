## Training Structure

Each exercise has two branches:
- **`/skeleton`** - Contains TODOs and hints for students to implement
- **`/complete`** - Contains fully implemented solutions for reference

### Branch Pattern
\`\`\`
ilt/202512.0/{level}/{topic}/{version}
\`\`\`

Example:
- \`ilt/202512.0/basics/hello-world-back-office/skeleton\`
- \`ilt/202512.0/basics/hello-world-back-office/complete\`

# Part 1: Basics

## 1. Hello World Back Office

**Branch:** \`ilt/202512.0/basics/hello-world-back-office/skeleton\` → \`complete\`

### Overview
Learn the fundamentals of creating a Back Office controller in Spryker. This is your first step into Spryker development, creating a simple "Hello World" page in the administration panel.

### Learning Objectives
- Create a new Spryker module in the project namespace
- Implement a Back Office controller  
- Create a Twig template for the view
- Access the page through Back Office URL
