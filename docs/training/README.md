# Spryker Backend Development Training

This directory contains comprehensive training materials for Spryker backend development.

## Training Manual

**Main Document:** [SPRYKER_TRAINING_MANUAL.md](./SPRYKER_TRAINING_MANUAL.md)

This 11-chapter manual covers everything from basic "Hello World" to advanced OMS state machines.

## Training Modules

The training is divided into two parts:

### Part 1: Basics (Chapters 1-5)
Foundation concepts for Spryker development

### Part 2: Intermediate (Chapters 6-11)  
Advanced features and integrations

## Using This Training

1. Clone the repository
2. Check out the `/skeleton` branch for each module
3. Follow the TODOs to implement features
4. Compare with `/complete` branch for solutions
5. Refer to the manual for detailed explanations
